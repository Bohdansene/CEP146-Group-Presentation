# AI Benefits and Limitations - Research Notes

**Project:** CEP146 - Can AI Replace Programmers?
**Responsible for:** Slides 4-6

## Slide 4 - Benefits of AI in Programming

AI tools help programmers work faster and improve productivity.

Main benefits:
- Faster development and repetitive task automation.
- Better productivity and focus on complex problems.
- Explanations of unfamiliar code.
- Documentation and code comment support.

## Slide 5 - Limitations and Risks

Main limitations:
- Incorrect code and bugs.
- Security vulnerabilities.
- Misunderstanding complex requirements.
- Overdependence on AI tools.

According to the 2025 Stack Overflow Developer Survey,
46% of respondents distrust AI-generated output accuracy.

## Slide 6 - AI-Generated Code Example

ChatGPT generated a C program to check even and odd numbers.

Benefit: It quickly produces a basic code example.

Limitation: The program does not validate the input
or check whether scanf succeeds.
