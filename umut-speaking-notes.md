**Project:** CEP146 - Can AI Replace Programmers?
**Slides:** 4-6

## Slide 4 - Benefits of AI in Programming

Now, I will talk about the benefits of AI in programming.

AI helps developers work faster and improve productivity. It can explain difficult code and help with documentation.

For example, when programmers work on a new project, AI can suggest solutions and save time.

This allows programmers to focus on more complex problems.

## Slide 5 - Limitations and Risks of AI

However, AI also has some limitations.

First, AI can generate incorrect code. Sometimes the code looks correct, but it has bugs.

Second, AI can create security risks.

AI also does not always understand complex projects or what the user really wants.

According to the 2025 Stack Overflow Developer Survey, 46 percent of respondents do not trust the accuracy of AI-generated results.

This is why human programmers still need to review AI-generated code.

## Slide 6 - AI-Generated Code Example

Here is a simple example of AI-generated C code.

I asked ChatGPT to write a program that checks if a number is even or odd.

The program uses an if-else statement and the modulo operator.

For example, if we enter eight, the program prints 'Even number.'

But there is a problem. The program does not check if the user enters a valid number.

This shows that AI can generate code quickly, but programmers still need to test and improve it.
